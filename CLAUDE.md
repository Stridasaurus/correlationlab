## What This Is

**CorrelationLab** — a browser-only React + TypeScript SPA that lets users build a portfolio of financial assets, visualize rolling correlation matrices, and compare cumulative returns across time windows (3M–20Y).

Deployed to GitHub Pages at `https://stridasaurus.github.io/correlationlab/` (Vite `base` is `/correlationlab/`).

## Data Sources

**Static JSON** (`public/data/`): pre-built correlation, returns, and price data covering ~2 years of default tickers (SPY, VOO, BND, etc.), generated by `scripts/fetch_data.py` at CI time.

**Live fetch** (`src/lib/fetchTicker.ts`): when a user adds a custom ticker, data is fetched from Stooq (stocks/ETFs/commodities/forex) or Yahoo Finance (crypto, fallback). Three independent CORS proxies are tried in sequence: corsproxy.io → allorigins.win → codetabs.com. Stooq is skipped entirely for crypto (maps BTC to a NYSE ETF instead). If all proxies fail, synthetic data is generated deterministically from the ticker string.

**Extended ranges** (5Y/10Y/20Y): static JSON only covers ~2 years, so in extended mode the static default tickers are excluded from charts and only live-fetched custom tickers are shown.

## State & Derived Data Flow in App.tsx

App.tsx manages all state and computes derived data through a chain of `useMemo` hooks:

```
[rangePreset, customTickers]
    │
    ▼
allDates          — extended ranges: longest custom ticker's date array
                  — standard ranges: returnsData.dates (static JSON)
    │
    ▼
mergedSeries      — static ticker series (excluded in extended mode)
                  + custom tickers aligned via alignToReferenceDates()
                    and normalized via normalizedCumulativeReturns()
    │
    ▼
filteredReturns   — sliced to last RANGE_DAYS[rangePreset] entries,
                  re-normalized to 0% at period start
    │
    ├──▶ rollingCorrelation  — Pearson correlation matrix over
    │                          filteredReturns[windowEndIdx-windowDays+1 … windowEndIdx]
    │
    └──▶ enrichedHoldings    — holdings decorated with price, value, weight, name, assetType
```

**`customTickers`** stores raw fetched dates+closes (not pre-aligned). Alignment to `allDates` happens in `mergedSeries`. This means range changes can re-align existing data without re-fetching — but a re-fetch is still triggered (`onAddTickerRef` effect) so data covers the new span.

## Correlation Computation

`rollingCorrelation` in App.tsx uses Pearson correlation on **daily returns** (not price levels) of the normalized cumulative-returns series. The window is controlled by `windowDays` (30/60/90/180d) and `windowEndIdx` (slider position within `filteredReturns`).

## Preset Portfolios

Eight built-in presets in `PRESETS` (App.tsx): Diversified Core, All-Weather, Crypto & Equities, US Sectors, 2008 Crisis, Tech Concentration, Inflation Trade, Factor Rotation. Each specifies `holdings[]` with allocations and a `totalValue` (inflation-adjusted for historical presets). `onLoadPreset` fetches all tickers in parallel and computes `quantity = round((totalValue × allocation) / latestPrice, 2)` so the portfolio starts with realistic share counts.

## Styling

TailwindCSS 3 with dark mode via `class`. The `dark:` variants are applied throughout. No CSS modules; all styling is inline Tailwind utility classes. Charts use Recharts with manual color theming via `contentStyle` overrides on tooltips.

## Tests

Tests live in `src/tests/`. `correlation.test.ts` covers the statistical core exhaustively. `fetchTicker.test.ts` covers `stooqSymbols` and `inferAssetType`. Use `.toBeCloseTo()` for floating-point assertions.
